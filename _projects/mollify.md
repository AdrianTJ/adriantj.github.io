**Mollify** is a Rust-native static analysis engine for Python codebases. In a single pass it surfaces dead code, dependency structure, architectural boundaries, duplication, and security issues — deterministically, without the guesswork of LLM-based tooling.

The goal is codebase intelligence you can trust in CI: fast, reproducible, and language-aware. Written in Rust for performance, it is designed to scale to large Python projects while keeping results stable across runs.

Check out the code on [GitHub](https://github.com/AdrianTJ/mollify).
