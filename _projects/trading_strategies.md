**Trading Strategies** is a web tool for tracking how different trading strategies perform over time. It provides a place to record, compare, and evaluate strategies against real market behavior, turning ad-hoc ideas into something you can measure and revisit.

Check out the code on [GitHub](https://github.com/AdrianTJ/Trading_Strategies).
